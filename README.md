# 👾 Pixu !!

Una aplicación nativa para iOS para gestionar tu colección de mangas, descubrir nuevos títulos y leer sus detalles.

Desarrollada 100% en **SwiftUI** + **SwiftData**.

## Características

- **Home**: Descubre mangas destacados y recomendaciones.
- **Colección**: Gestiona tu lista personal de mangas leídos, en lectura o pendientes.
- **Buscador**: Búsqueda potente por título, autor o género.
- **Pantalla de detalle**: Información completa del manga (sinopsis, capítulos, portada, estado, etc.).
- Persistencia local con **SwiftData** (modelado de entidades, relaciones y consultas reactivas).
- Arquitectura limpia con **MVVM**.
- Interfaz moderna y declarativa con SwiftUI.
- Soporte para dark mode y múltiples dispositivos (iPhone e iPad).

## Tecnologías utilizadas

- Swift 6
- SwiftUI
- SwiftData
- MVVM
- Async/Await

## Requisitos

- iOS 17.0 o superior
- Xcode 16 o superior
